HTTP Poll 模擬

首頁MQTT 客戶端(Push)HTTP Poll 模擬
模擬原理:Broker 上的 Retained message 相當於「伺服器上的最新資料」。Poll 每次都新建連線、讀取、馬上關閉,模仿 HTTP「一個 Request 對應一個 Response,一回合溝通即完結」。這是模擬,並非真正的 HTTP。

剩餘時間:60 秒 | 狀態:待機

「伺服器」資料位置(Topic):-

Poll:每次都主動詢問

HTTP Request 次數0
開啟連線次數0
200 有新資料0
304 沒有變化(白問)0
白問比例-
逾時或錯誤0

Push:訂閱一次,有新訊息才通知

額外詢問次數0
開啟連線次數0
收到通知次數0
無新訊息時的通知0

如何手動發布訊息(不用機器人)

開啟「MQTT 客戶端」頁,連線後在 Publish 區域輸入 Topic(上面顯示的 Topic)、勾選 Retain,Message 輸入例如「公告 #1」,按 Publish。
